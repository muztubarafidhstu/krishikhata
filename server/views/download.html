ইনস্টল

অ্যাপ ইনস্টল করার নিয়ম

  1. উপরের হলুদ "ডাউনলোড" বোতাম চাপুনkrishikhata.apk ফাইলটি নামবে।
  2. ডাউনলোড হওয়া ফাইলটি খুলুননোটিফিকেশন থেকে বা Files → Downloads থেকে।
  3. "Unknown apps" অনুমতি দিনফোন জানতে চাইলে Settings → Allow from this source চালু করে পেছনে আসুন। এটা একবারই লাগে।
  4. Install চাপুনহোম স্ক্রিনে সবুজ পাতার "কৃষিখাতা" আইকন আসবে।

অ্যাপটি Play Store-এ নয়, তাই এই অনুমতি চায়। অ্যাপ শুধু আপনার দোকানের হিসাবের ওয়েবসাইট খোলে; ফোনের অন্য কিছুতে হাত দেয় না।

ব্যবহার

প্রথমবার ব্যবহার

  1. দোকানের ঠিকানা লিখুনযেমন দোকানের ঠিকানা karim.{{DOMAIN}} হলে শুধু karim লিখুন। অ্যাপ মনে রাখবে।
  2. মোবাইল নম্বর ও পাসওয়ার্ড দিয়ে লগইনমালিক ও সেলার — সবার নিজের আইডি।
  3. নতুন বিক্রিপণ্যের নাম লিখে বা সার/বীজ/কীটনাশক বেছে পণ্যে চাপুন, ক্রেতার নম্বর দিন, সেভ করুন — মেমো তৈরি।
  4. মেমো ডাউনলোড বা প্রিন্টPDF ফোনের Downloads/KrishiKhata ফোল্ডারে সেভ হয়।
