# কৃষিখাতা Android অ্যাপ

অ্যাপটি একটি হালকা (২০ KB) "শেল" — ভেতরে আপনার ওয়েবসাইট (`<দোকান>.rafid5.com`) খোলে। তাই ওয়েবসাইটে যে নতুন ফিচার আসে, অ্যাপে নিজে থেকেই চলে আসে; অ্যাপ আপডেট করতে হয় না।

## অ্যাপ যা করে
- প্রথমবার দোকানের ঠিকানা চায় (যেমন `karim`) এবং মনে রাখে।
- ইনভয়েস PDF/ছবি ফোনের **Downloads/KrishiKhata** ফোল্ডারে সেভ করে খুলে দেয়; প্রিন্টও করা যায়।
- ইন্টারনেট না থাকলে "সংযোগ নেই" পেজ দেখায়।
- শুধু `rafid5.com`-এর ঠিকানা অ্যাপের ভেতরে খোলে; অন্য সব লিংক ফোনের ব্রাউজারে।
- লগইন পেজে "অন্য দোকানের ঠিকানা" বোতাম দিয়ে দোকান বদলানো যায়।
- Android 7.0 বা তার পরের সব ফোনে চলে।

## দোকানদারকে অ্যাপ দেওয়া
ডাউনলোড লিংক: **https://rafid5.com/krishikhata.apk** (ওয়েবসাইটের লগইন পেজেও বোতাম আছে)।

ফোনে ইনস্টল: লিংক খুলুন → Download → ফাইলটি খুলুন → "Install unknown apps / অজানা উৎস" অনুমতি চাইলে **Allow** → Install।
(Play Store-এ না থাকায় এই অনুমতি একবার দিতে হয়।)

## সাইনিং কী (খুব জরুরি)
`krishikhata-release.jks` ফাইল আর তার পাসওয়ার্ড ছাড়া অ্যাপের **নতুন ভার্সন** বানানো যাবে না — ফোন অন্য কী দিয়ে সাইন করা আপডেট নেয় না। ফাইল ও পাসওয়ার্ড Google Drive-এ এবং আলাদা জায়গায় রাখুন। **GitHub-এ কখনো তুলবেন না।**

## নতুন ভার্সন বানানো (দরকার হলে)
GitHub → রিপোজিটরি → Settings → Secrets and variables → Actions → এই ৪টি secret যোগ করুন:
`KEYSTORE_BASE64` (কী-ফাইলের base64: `base64 -w0 krishikhata-release.jks`), `KEYSTORE_PASSWORD`, `KEY_ALIAS` (= `krishikhata`), `KEY_PASSWORD`।
তারপর Actions → "Android app" → Run workflow → শেষ হলে Artifacts থেকে APK নামান।

## Google Play Store (পরে, ঐচ্ছিক)
Google Play Developer অ্যাকাউন্ট (একবার $25) → নতুন অ্যাপ → একই কী দিয়ে বানানো AAB আপলোড (`gradle bundleRelease`) → প্রাইভেসি পলিসির লিংক, স্ক্রিনশট, বিবরণ → রিভিউ (কয়েক দিন)।
