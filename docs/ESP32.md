# ESP32 + SIM800L SMS গেটওয়ে

ওয়েবসাইট নিজে SMS পাঠায় না। সে SMS গুলো একটি লাইনে রাখে, আর আপনার দোকানে/বাসায় থাকা ESP32 কয়েক সেকেন্ড পরপর ইন্টারনেট দিয়ে সেগুলো নিয়ে SIM মডিউল দিয়ে পাঠিয়ে দেয়।

```
ওয়েবসাইট (সার্ভার) ──HTTPS──> ESP32 (WiFi) ──UART──> SIM800L ──মোবাইল নেটওয়ার্ক──> গ্রাহকের ফোন
```

## যা লাগবে

- ESP32 DevKit (যেকোনো সাধারণ ESP32)
- SIM800L মডিউল (বা SIM7600 / A7670 — টেক্সট মোডে একই AT কমান্ড)
- **আলাদা পাওয়ার সাপ্লাই** SIM800L-এর জন্য: 3.7–4.2V, কমপক্ষে 2A (একটি 18650 Li-ion ব্যাটারি, বা 5V→4V buck converter)
- একটি প্রিপেইড সিম (2G/GSM চালু থাকা অপারেটর; SIM800L শুধু 2G। 2G না থাকলে A7670 নিন)
- 1000µF ক্যাপাসিটর SIM800L-এর VCC-GND-এর কাছে (রিসেট কমায়)

## তার জোড়া

| SIM800L | ESP32 |
|---|---|
| TXD | GPIO16 (RX2) |
| RXD | GPIO17 (TX2) |
| GND | GND (**অবশ্যই** পাওয়ার সাপ্লাইয়ের GND-ও একসাথে) |
| RST | GPIO4 (ঐচ্ছিক) |
| VCC | আলাদা 4V সাপ্লাই (ESP32-এর 3.3V থেকে **নয়**) |

## প্রোগ্রাম আপলোড

1. Arduino IDE → Boards Manager → **esp32 by Espressif** ইনস্টল।
2. Library Manager → **ArduinoJson** (v7) ইনস্টল।
3. `esp32/sms_gateway/config.example.h` কপি করে একই ফোল্ডারে `config.h` নাম দিন, ভেতরে বসান:
   - `WIFI_SSID`, `WIFI_PASS` — দোকানের WiFi
   - `SERVER_HOST` — আপনার ডোমেইন (যেমন `krishikhata.com.bd`)
   - `GATEWAY_KEY` — সার্ভারের `.env`-এর `GATEWAY_KEY` হুবহু
4. `sms_gateway.ino` খুলুন → Board: **ESP32 Dev Module** → Upload।
5. Serial Monitor (115200) খুলে দেখুন: `[wifi] connecting... ok`, `[modem] network: +CREG: 0,1` (1 বা 5 মানে নেটওয়ার্কে আছে)।

## পরীক্ষা

ওয়েবসাইটে সুপার অ্যাডমিন → **SMS / OTP লগ** → "গেটওয়ে অনলাইন" দেখাবে।
**সেটিংস ও OTP → টেস্ট SMS** দিন → কয়েক সেকেন্ডে ফোনে আসবে, লগে "পাঠানো" দেখাবে। তারপর **OTP চালু করুন**।

## জেনে রাখুন

- SMS ইংরেজিতে যায় (একটি SMS-এ ১৬০ অক্ষর), কারণ বাংলা SMS-এ মাত্র ৭০ অক্ষর ধরে আর বেশি খরচ হয়। অ্যাপের ভেতরের নোটিফিকেশন বাংলাতেই দেখায়।
- পুরোনো OTP (১০ মিনিটের বেশি) পাঠানো হয় না — বাতিল হয়ে যায়।
- একটি SMS ৩ বার ব্যর্থ হলে "ব্যর্থ" হিসেবে লগে থাকে।
- ESP32 সার্ভারের সাথে HTTPS-এ কথা বলে এবং গোপন `GATEWAY_KEY` দিয়ে নিজেকে চেনায়। কোডে সার্টিফিকেট যাচাই বন্ধ রাখা আছে সহজ করার জন্য (`setInsecure`)। আরও নিরাপদ করতে আপনার সাইটের root certificate `client.setCACert()` দিয়ে বসাতে পারেন।
- এই কোড এখনো আসল হার্ডওয়্যারে পরীক্ষা করা হয়নি — প্রথমবার Serial Monitor খুলে রেখে চালাবেন। সমস্যা হলে লগ পাঠালে ঠিক করে দেওয়া যাবে।
